# Java Link

> **初心者の今しか生まれない「わからない」を教材に。**
>
> **― 学びながら開発する、開発しながら学ぶ ―**

Java Link は、Java初心者向けの学習Webアプリです。

Javaを学ぶ中で初心者だからこそ感じる「わからない」を学習資産と考え、初学者の視点から教材を作り、自分自身もその教材を使いながら成長することを目指して開発しています。

---

# 学習モード

## ① コードを左から読む

Javaコードを左から順番に読み進めながら、それぞれのキーワードや構文の意味を理解する学習モードです。

### 目的

- Java文法を理解する
- コードを読めるようになる

---

## ② Javaタウンをつくろう

コードを組み立てながら、Javaプログラムの構造を自然に身につける学習モードです。

### 目的

- コードを書く力を身につける
- Javaプログラムの構造を理解する
