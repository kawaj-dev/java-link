# Java Link

> **初心者の今しか生まれない「わからない」を教材に。**
>
> **― 学びながら開発する、開発しながら学ぶ ―**

Java Link は、Java初心者向けの学習Webアプリです。

開発者がJavaを学び始めたときに感じた「わからない」を貴重な学習資産と考え、初学者の視点から教材を作っています。

開発者自身もその教材を使いながら学び、教材とともに成長することを目指しています。

---

# 教材設計

Java Linkでは、学習段階によって説明を書き換えません。

「今はここだけ覚えれば大丈夫」や
「今は覚えなくてもいいです」という説明はありません。

正しい内容を、できるだけわかりやすい言葉で伝えます。

**説明は変わりません。**

**変わるのは、学習者の理解です。**

学習を進めるほど、同じ説明から読み取れる内容が増え、見える景色が変わっていきます。

---

# 学習モード

## ① コードを左から読む

Javaコードを左から順番に読み進めながら、それぞれのキーワードや構文の意味を理解する学習モードです。

### 目的

- Java文法を理解する
- コードを読めるようになる

---

## ② Javaタウンをつくろう

コードを組み立てながら、Javaプログラムの構造を自然に身につける学習モードです。

### 目的

- コードを書く力を身につける
- Javaプログラムの構造を理解する
